Disinformation Detection

Binary classification of texts as disinformation vs. non-disinformation.

This edition participation possible online and onsite!

Task Overview

Binary classification of texts as disinformation vs. non-disinformation, building on existing resources such as MIPD for Polish. English-language data (MultiDis, MALINT) is also included to encourage broader participation. Co-organized with NASK National Research Institute, a leading Polish institution involved in monitoring and countering disinformation.

Languages covered:

  • Polish
  • English
  • Surprise language/s for test data

Data & Resources

Training Data. The task builds on several publicly available datasets and benchmark resources for disinformation detection. These datasets were introduced in papers presented at major ACL venues, including EMNLP, ACL, and EACL, and they are directly relevant to the current task because they cover disinformation detection and datasets. When writing a system description paper, authors are requested to cite the below papers.

  • MIPD — Modzelewski et al., 2024: Polish disinformation dataset with multiple topics. Data available at the MIPD GitHub repository.
  • PCoT — Modzelewski et al., 2025: MultiDis English disinformation dataset covering many topics. Data available at the PCoT GitHub repository.
  • MALINT — Modzelewski et al., 2026: English disinformation MALINT dataset. Data available at the MALINT GitHub repository.

Additional Data. Participants may use any relevant public or private disinformation and misinformation datasets they consider useful for developing their systems, and they are encouraged to explore additional resources beyond the ones listed above when appropriate.

Test Data. Test data will be released via this website in December. It will be available in Polish, English and surprise Slavic language/s.
