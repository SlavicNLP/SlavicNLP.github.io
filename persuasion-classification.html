Persuasion Classification

Persuasion Techniques Detection & Classification (2nd edition)

Task Overview

Detection and classification of persuasion techniques at the sentence level in three Slavic languages: Bulgarian, Polish and Russian in two text types: (a) parliamentary debates, and (b) disinformation-related social media posts. The task uses a taxonomy of 25 persuasion techniques and builds on prior paragraph-level annotated dataset from the Slavic NLP 2025 Shared Task.

Data & Resources

The task builds on span-level annotated datasets from SemEval-2020 Task 11, SemEval-2021 Task 6, SemEval-2023 Task 3, and the Slavic NLP 2025 Shared Task. Training, development, and test data will be released via this website and/or a dedicated shared task repository.
